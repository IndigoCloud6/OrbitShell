# OrbitShell IDE 界面

- ide-reference.png：用户确认的原始设计稿，1586 × 992。
- implementation-compact.png：共用正式组件渲染的开发比对场景，默认紧凑密度。
- comparison.png：原设计稿与最新紧凑实现的并排对照。

设计稿完成三轮同尺寸布局调整后，用户反馈系统界面字号偏大，因此最新默认界面改为紧凑密度：菜单与连接名称约 14.1，面板标题约 15.6，文件名约 12.5。终端字号独立配置。可在“设置 → 外观 → 界面密度”切换舒适密度。

开发模式的 /#/design-review 使用明确隔离的虚构数据，共用正式工作台、文件列表、会话栏、终端及传输表格组件。它不读取系统凭据、真实连接配置或真实服务器，也不随生产构建开放。截图中的连接、日志、文件和传输数据用于稳定的视觉比较。

已确认界面无页面级横向溢出，并检查了 1586 × 992 和最小窗口宽度 960 的显示、连接搜索及文件侧栏收起交互。源码通过 TypeScript 与前端构建；Rust 进度通道通过 dev 编译。自动化回归测试遵从用户约定保持未执行。

连接日志仅记录本次运行中的状态事件；不会把终端正文或密码持久化为日志。文件传输进度使用 Rust 读取的实际字节数与文件大小；无法获取总大小时显示不确定进度。
