- comparison.png：原设计稿与最新紧凑实现的并排对照。
- connection-login-compact-v2.png：用户确认的第二版连接服务器弹窗设计稿，使用虚构连接信息。
- workspace-start.png：用户确认的工作区启动页设计稿，采用快速连接、最近会话行列表及快捷操作分区。

设计稿完成三轮同尺寸布局调整后，用户反馈系统界面字号偏大，因此最新默认界面改为紧凑密度：菜单与连接名称约 14.1，面板标题约 15.6，文件名约 12.5。终端字号独立配置。可在“设置 → 外观 → 界面密度”切换舒适密度。

开发模式的 /#/design-review 使用明确隔离的虚构数据，共用正式工作台、文件列表、会话栏、终端及传输表格组件。它不读取系统凭据、真实连接配置或真实服务器，也不随生产构建开放。截图中的连接、日志、文件和传输数据用于稳定的视觉比较。

已确认界面无页面级横向溢出，并检查了 1586 × 992 和最小窗口宽度 960 的显示、连接搜索及文件侧栏收起交互。源码通过 TypeScript 与前端构建；Rust 进度通道通过 dev 编译。自动化回归测试遵从用户约定保持未执行。

连接日志仅记录本次运行中的状态事件；不会把终端正文或密码持久化为日志。文件传输进度使用 Rust 读取的实际字节数与文件大小；无法获取总大小时显示不确定进度。

比对入口同时提供快捷指令分组与列表、AI 执行记录与输出、远程文本编辑、快照抽屉及版本对比。它们复用正式组件，数据源为该路由内的虚构数据；不会读取真实执行记录、保存指令、访问本地快照或发起远程读写。

连接服务器弹窗采用第二版紧凑设计：默认紧凑密度下宽约 520px，用户名与主机合并展示，已保存密码用单行状态表示，移除独立的认证信息双列和大提示卡片。底部按钮高约 32px，手动输入、凭据读取错误和私钥口令等状态按内容展开，保留凭据更换、清除及记住选项的原有行为。

工作区没有打开的终端或文件时显示启动页，主区域提供快速连接输入、最近会话行列表和快捷操作。远程文件侧栏在启动页默认收起，连接建立后恢复原有偏好；窄工作区中快捷操作移到列表下方，最近条目的名称和地址改为两行。最近会话来自真实成功连接，已保存连接只持久化 ID 与时间，临时会话不持久化认证信息。开发比对入口 `/#/design-review?view=start` 使用独立虚构数据复用启动页视图，不读取真实连接或最近会话，也不发起连接；本轮实现未运行浏览器比对、类型检查、测试或构建。

窄窗口会限制两侧面板的实际宽度，为工作区留出空间，放宽窗口后恢复用户选择的宽度。底部工具默认高度为 200px，所有标签共用可调整的高度，不设置最小高度限制，并保留高度记忆；AI 面板较窄时采用列表与详情切换，详情左侧的返回按钮可回到记录列表。紧凑列表只展示所属会话、命令和状态，退出码与耗时在详情中显示。

2026-11-12 本轮已在 1586 × 992 与 960 × 720 查看布局，并操作工具标签切换、指令分组、AI 详情返回、快照预览和版本对比；也查看了浏览器预览中的新建连接与外观设置，以及深浅主题。四个工具标签共用高度，窄窗口没有页面级横向溢出。本轮未另行运行类型检查、测试或构建，也未连接真实服务器进行远程操作。

AI 会话工作区采用 `ai-terminal-workspace.png` 设计稿：执行过程进入扁平独立标签，底部 AI 工具只保留 Agent 连接状态和会话入口。默认复用每个 Agent / SSH 会话的独立 POSIX Shell，后台持续读取真实输出；标签具有 AI 标记、运行状态和新输出点，关闭独立标签只隐藏视图。已有人工会话支持通过 MCP 显式接管原 PTY，原标签显示 Agent 并锁定人工输入，可从工具栏或右键菜单交回人工；接管模式不猜测命令完成或退出码。此轮仅实施代码，未运行测试、类型检查、构建或界面验收。

执行历史作为工作区工具标签接入，左侧活动栏提供独立历史图标。标签内部采用主机列表和紧凑记录表，支持关键词、人工 / AI 来源过滤、分页和复制；历史只来自客户端提交的命令，不调用远端 history。MCP 设置增加自动启动开关，默认保持手动开启，启动失败显示原因。此轮仅实施代码和说明，未启动 dev，也未执行测试、类型检查、构建或界面检查。

原终端接管增加明确入口：原会话标签右键或终端信息栏“交给 AI 接管”，选择已经连接的 MCP Agent。独立标签标明“独立 Shell”，原标签接管标记 Agent；MCP 回包同时说明 mode、terminalId 与 sharesOriginalTerminal。运行约束统一在 docs/mcp-agent-rules.md，由 MCP 初始化 instructions 直接引用。此轮未做测试、构建、浏览器检查或重启 dev，也未连接真实服务器验证接管。

执行历史界面改为单行命令与稳定行高，时间使用时间 / 日期双行，用户名并入主机次要信息，缩窄主机导航并减少横向最低列宽。历史页字号、命令字号和辅助字号通过主题密度 token 统一，显式覆盖内部 Text 默认字号，命令使用常规字重。长命令点击进入详情复制，常驻说明改为提示图标，复制反馈放入底栏；窄工作区使用主机下拉筛选。此轮仅修改界面和说明，未执行测试、构建、检查、截图或 dev 重启。

MCP 的设置清单改为从真实路由读取，并显示会话控制协议版本。为只暴露旧七工具的宿主，在 send_input 增加显式 action=takeover / release 兼容控制；两者必须空 data，不会发送字符或新建 PTY。规范、工具说明和 list_sessions 提示同步更新。此轮未运行测试、构建、检查、dev 重启或真实远端操作。
